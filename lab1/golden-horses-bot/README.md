# Golden Horses Bot 🐴

Telegram-бот для записи на прогулки на лошадях в Токсово (СПб).

## Возможности

- 🐴 Запись на прогулку (услуга, анкета, дата, время)
- 📋 Просмотр своих записей
- 💰 Прайс-лист
- 📍 Как добраться
- 📝 Памятка посетителя
- 📞 Контакты
- ℹ️ О нас

## Установка

```bash
git clone <repo>
cd golden-horses-bot
pip install -r requirements.txt
