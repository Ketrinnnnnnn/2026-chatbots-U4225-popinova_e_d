# Видео-демо работы бота

**Ссылка:** https://disk.yandex.ru/i/iUX-i0gbdCyfcQ

## Что показано в видео

- Запуск бота (`python bot.py`)
- Команда `/start` — главное меню
- Запись на прогулку (полный путь)
- Заполнение анкеты участника
- Подтверждение заявки
- Просмотр «Мои записи»
- Команды «Цены», «Как добраться», «Памятка», «Связаться», «О нас»
