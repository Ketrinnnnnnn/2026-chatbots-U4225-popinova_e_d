# Лабораторная работа №1
## "Создание первого Telegram-бота без программирования"

---

## 1. Описание задачи

### Какую проблему решает бот

**Проблема:** Клиентам конного клуба «Golden Horses» (Токсово, Санкт-Петербург) неудобно записываться на прогулки по телефону. Администратор вынужден принимать звонки вручную, уточнять данные каждого всадника, подбирать лошадь и время.

**Решение:** Telegram-бот, который позволяет клиенту:
- Самостоятельно выбрать тип прогулки
- Заполнить анкету (пол, возраст, рост, вес, опыт верховой езды)
- Выбрать дату и время
- Оставить контактные данные

Инструктор получает заявку и **вручную подтверждает** — подбирает лошадь и время под параметры всадника.

### Почему выбрали именно эту задачу

1. **Реальная бизнес-задача** — конный клуб существует, работает, и бот может улучшить его процесс.
2. **Простой функционал** — не требует сложной логики, хорошо подходит для первой лабораторной.
3. **Практическая ценность** — можно показать руководству клуба и доработать до продового состояния за вознаграждение.
4. **Соответствует теме курса** — Vibe Coding для реальных бизнес-задач.
