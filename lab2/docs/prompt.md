# Промпт для LLM — Лабораторная работа №2

## Задача: добавить работу с CSV-файлами в бота Golden Horses

Улучши моего Telegram-бота "Golden Horses" — добавь работу с CSV-файлами.

ТЕКУЩИЙ ФУНКЦИОНАЛ:
- /start — главное меню с кнопками
- Запись на прогулку (услуга, анкета для КАЖДОГО участника, дата, время)
- Мои записи
- Цены, Как добраться, Памятка, Связаться, О нас
- Записи хранятся в data/bookings.json

НОВЫЙ ФУНКЦИОНАЛ — работа с CSV-файлами:

1. ДОБАВИТЬ КНОПКИ В ГЛАВНОЕ МЕНЮ:
   - "🐎 Наши лошади" (callback: menu_horses)
   - "👥 Наши инструкторы" (callback: menu_instructors)

2. РАБОТА С ЛОШАДЬМИ (data/horses.csv):
   Структура: name,breed,age,color,character,height_cm,max_weight_kg
   - Показать список всех лошадей
   - Поиск по имени или породе
   - Проверка веса всадника

3. РАБОТА С ИНСТРУКТОРАМИ (data/instructors.csv):
   Структура: name,specialization,experience_years,phone,languages
   - Показать список всех
   - Поиск по специализации

4. ПРИ ЗАПИСИ НА ПРОГУЛКУ:
   - После ввода веса участника проверить наличие подходящей лошади
   - Если вес > 105 кг — предупредить

ТРЕБОВАНИЯ:
- Использовать стандартную библиотеку csv
- Обработка ошибок (файл не найден, пустой)
- Красивое форматирование с эмодзи
- Не ломать существующий функционал
